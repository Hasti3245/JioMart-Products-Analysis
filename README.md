# 📊 JioMart Product Data Analysis  

## 📌 Project Overview  
This project presents an end-to-end data analytics workflow on JioMart product data. The objective was to clean, transform, and analyze product-level data to extract meaningful insights related to pricing, discounts, and product distribution.  

This project demonstrates practical skills in:  
- Data cleaning and preprocessing  
- Exploratory data analysis  
- Business intelligence reporting  
- Dashboard development using Power BI  

---

## 📂 Dataset Description  
**Source:** JioMart product dataset  
**Type:** E-commerce product data  

The dataset includes information such as product names, categories, prices, and discounts. The raw data contained inconsistencies and formatting issues, which required preprocessing before analysis.  

---

## 🧹 Data Cleaning & Transformation (MS Excel)  
Data preparation was performed using **Microsoft Excel**.  

### Cleaning Steps  
- Removed duplicate records  
- Handled missing and inconsistent values  
- Standardized product names and categories  
- Cleaned and formatted price and discount columns  
- Structured the dataset for analysis  
- Prepared final cleaned dataset for visualization  

---

## 📊 Power BI Dashboard  
The cleaned dataset was used to build an interactive Power BI dashboard that provides insights into:  

- Product price distribution  
- Discount analysis across products  
- Category-wise comparison  
- Key trends and patterns  
- Identification of high-discount and high-value products  

**Dashboard File:** `visualizations/JioMart_Products.pbix`  

---

## 🔍 Key Analytical Insights  
- Identified products offering the highest discounts  
- Analyzed pricing trends across different categories  
- Compared product distribution and value patterns  
- Highlighted opportunities for pricing and discount optimization
